How It Works

Each button injects realistic attack-pattern feature rows directly into data/features.csv.

The decision loop picks up the rows, scores them with the ML model, and writes detections to alerts.jsonl.

The dashboard then visualizes everything in real-time. No Scapy or admin privileges required.
